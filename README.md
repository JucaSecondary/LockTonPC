# LockTonPC
Les fichiers et les étapes nécessaires pour faire une excellente blague
## Étapes
1. Paramètres -> Accessibilité -> Pointeur Souris -> Customiser l'image du curseur -> Définir à un fichier .cur
2. Paramètres -> System -> Sons -> Plus d'options son -> Sauvegarder le schéma de sons -> Modifier le son d'un élément à un fichier .wav -> Appliquer
   - Open Program se déclenche à chaque changement d'onglet

## Fix (car sinon ça risque d'être dérangeant)
1. Paramètres -> Accessibilité -> Pointeur Souris -> Reset
2. Paramètres -> System -> Sons -> Plus d'options son -> Supprimer le schéma de sons
